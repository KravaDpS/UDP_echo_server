# STM32F429ZI Nucleo UDP-Server Example

Проект является примером развертывания UDP-сервера на отладочной плате NUCLEO-F429ZI.

## Средства разработки

- Среда разработки: STM32CubeIDE v1.10.1
- Используются библиотеки: CMSIS, BSP, HAL
- Отладочная плата: NUCLEO-F429ZI
- Микроконтроллер: STM32F429ZIT6U

## Настройка сетевого подключения

Пример поддерживает протокол DHCP для автоматического назначения IP-адреса. В проекте IP-адрес задается статично в файле `UDP_Echo_Server/Inc/main.h`.
Номер UDP-порта задается в файле `UDP_Echo_Server/Inc/udp_server.h` и используется при инициализации UDP-сервера.
Параметры сетевого подключения, используемые в примере:

- IP-адрес: `172.18.56.200`
- UDP-порт: `32001`

## Особенности проекта

Исходный проект UDP-сервера создан на основе примера для отладочной платы STM324x9I_EVAL. Нельзя открывать проект в конфигураторе STM32CubeMX через файл `UDP_Echo_Server.ioc`. Конфигуратор внесет критические изменения в исходный код. Для подключения дополнительной периферии используется пакет поддержки платы BSP.
